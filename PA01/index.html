HTML,CSS Y JAVASCRIPT:

Son los tres pilares fundamentales del desarrollo web que trabajan juntos para crear paginas web dinamicas e interactivas.
HTML se encarga de la estructura y el contenido. CSSdel diseño y la presentación, y JAVASCRIPT de la interactividad y la funcionalidad.

DEFINICIONES:

HTML(HyperText Markup Languaje)

Es el lenguaje de marcado que define la estructura y el contenido de una pagina web. Utiliza etiquetas para delimitar diferentes elementos, como párrafos, encabezados. imagenes, enlances, etc.

CSS(Cascading Style Sheets)

Es un lenguaje de estilos que se utiliza para controlar la presentacion de una página web. Permite definir aspectos como los colores, fuentes, tamaños, margenes, etc., de los elementos HTML.

JAVASCRIPT(PROGRAM LANGUAJE)

Es un lenguaje de programacion que permite agregar funcionalidad a una pagina web. Permite manipular elementos HTML, responder a eventos del a realizar calculos, etc.

ANALOGIA DE LA WEB Y UNA CASA:

HTML

Estructura de la casa.

Es como los cimientos, las paredes, techos, y distribuccion de las habitaciones.

HTML define la estructura básica de una página web: que elementos hay(titulo,párrafos, botones,imégenes,etc)pero sin preocuparse por como se ven.

CSS

Decoración y estilo de la casa.

Es la pintura de las paredes, el tipo de piso, los muebles, las cortinas, el diseño de la cocina.

CSS se encarga de cómo se ve la pagina: colores, fuenes, margenes, alineacion, estilos responsivos...lo visual.

JAVASCRIPT

Los sistemas electricos y eléctronicos de la casa.

Es como los interruptores que encienden luces, las puertas automáticas, el termostato inteligentes.

JavaScript añade funcionalidad e interactividad haciendo que pasen cosas como respuesta a una evento.
